
# MelodyGuitar Project Instructions

You are helping develop MelodyGuitar, a guitar-learning web application.

Important requirements:
- Preserve all six guitar strings.
- Keep fretboard and TAB synchronized.
- Ensure played notes match displayed notes.
- Preserve fingerstyle mode.
- Preserve synchronized bass and melody playback.
- Maintain realistic Karplus-Strong guitar sound.
- Keep tempo, play, pause, reset and repeat controls working.
- Test changes before committing.
- Do not remove existing working features.
